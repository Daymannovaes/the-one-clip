OneClip

The One Clip to Rule Them All

A media processing CLI that wraps ffmpeg into ergonomic commands for cutting, compressing, transcribing, and editing video files.

100% free & open source
$ npx install-oneclip wizard
$ npm install -g oneclip direct
Get Started View on GitHub

Features

Everything you need to process video from the command line.

cut

Cut Segments

Extract video segments by start and end timestamps. oneclip cut video.mkv --start 00:01:00 --end 00:05:00

zip

Compress

H.264 compression with configurable quality and speed presets. Supports batch processing for multiple files.

srt

Transcribe

Generate SRT subtitles from video using whisper.cpp. Handles WAV conversion automatically.

mute

Remove Silence

Automatically detect and remove silent segments. Configurable threshold, duration, and minimum segment length.

wav

Extract Audio

Extract audio tracks to WAV format. Select or remove specific audio tracks from multi-track files.

img

Thumbnails

Extract thumbnails using scene detection or fixed intervals. Generate styled YouTube thumbnails with text overlays.

join

Join Videos

Concatenate two or more video files into a single file. Fast stream copy with no re-encoding. oneclip join part1.mkv part2.mkv

obs

OBS Auto-Rename (macOS)

Listens for OBS recordings and shows a native macOS dialog to rename the file when it stops. No terminal focus needed.

Usage

Simple commands that do the right thing by default.

Terminal 
# Cut a segment from a video
$ oneclip cut video.mkv --start 00:01:00 --end 00:05:00

# Compress with high quality
$ oneclip compress video.mkv --verygood --speed slow

# Batch compress all MKV files
$ oneclip compress-batch *.mkv

# Generate subtitles
$ oneclip transcript video.mkv

# Remove silence from a recording
$ oneclip silence-remove video.mkv --threshold -30dB

# Extract thumbnails via scene detection
$ oneclip thumbnail-frames video.mkv --count 5

# Generate a styled thumbnail from an image
$ oneclip thumbnail screenshot.png --title "My Video"

# Join multiple video files into one
$ oneclip join part1.mkv part2.mkv part3.mkv

# Watch OBS and rename recordings via macOS popup (macOS only)
$ oneclip obs-rename

All commands accept -o <file> to specify an output path. If omitted, outputs are named <input>_<timestamp>.<ext>.

AI Pipeline

Claude Code commands that automate your entire content creation workflow.

/

/video-pipeline

Full production workflow in one command. Audio track selection, transcription, AI-generated titles, chapters, and descriptions, silence removal, thumbnails, and compression — all automated.

/

/video-describe

Feed it an SRT transcript, get back YouTube-ready titles, thumbnail text, chapters, and tags. Turns your raw recording into publish-ready metadata.

These are Claude Code slash commands. Install OneClip, open Claude Code in your project, and run them.

Installation

Up and running in under a minute.

Recommended

Checks dependencies, then installs the CLI globally.

$ npx install-oneclip

npm

$ npm install -g oneclip

From source

$ git clone https://github.com/daymannovaes/the-one-clip.git
$ cd the-one-clip
$ npm install
$ npm link
# `oneclip` is now available globally

Prerequisites

# Node.js 18+, ffmpeg and ffprobe required

# macOS
$ brew install ffmpeg

# Ubuntu/Debian
$ sudo apt install ffmpeg

# Optional: whisper.cpp for transcription
# See https://github.com/ggerganov/whisper.cpp
